# Atlas Lattice Review Context Map

This is a public, non-canonical orientation layer for [Atlas Lattice corpus review](./README.md). It does not include private-source contents or raw private locators.

| Evidence layer | Public review status | Authority boundary |
|---|---|---|
| Canon | The [Canon Register](https://github.com/atlaslattice/alexandria-canon-register) identifies the locked architecture baseline. | Only the Canon Register and Alexandria’s baseline-lock policy can authorize public canon projection. |
| Source index | 2,163 staged source records: 271 GitHub, 1,812 redacted Notion, and 80 redacted OneDrive observations. | A container record is not an atomic delta or a canon claim. |
| Atomic candidates | 21 source-bounded candidates. Each has an explicit `quarantine_result`. | Candidates remain review-only and are not deployment or canon authorization. |
| Quarantine | Keyword-matched records are preserved but excluded from normal public projection and retrieval. | A keyword match is a policy-routing result, not proof of attribution or compromise. |
| Recovery | Public Atlas Lattice v5 observations and recovery references are retained as reconstruction evidence. | Public runtime material does not override Canon Register authority. |
| Pendragon | Alexandria’s named append-only provenance-event protocol records artifact observation, derivative use, evidence receipts, decisions, and review state. | Pendragon cannot mutate a source or promote canon. |

## Coverage Boundary

The accessible Notion inventory has been traversed, while full semantic atomic extraction remains ongoing. OneDrive remains incomplete because browser results cannot produce a full immutable manifest with item IDs, timestamps, eTags, and hashes. The complete cross-platform atomic ledger remains a staged objective.

> **Review availability is not authority.** This repository is intended to help reviewers find and assess source-bounded material while keeping canon, private access, quarantine, and deployment boundaries explicit.
