# Review Index Policy

This repository is a **non-canonical review distribution layer**. It is intended to support source tracing and disciplined review of the corpus.

## Publication Rules

Public source locations may be linked directly when they are already publicly reachable. Non-public records must remain represented by an opaque provenance reference until Daavud explicitly authorizes a specific access channel and any applicable rights, confidentiality, and institutional requirements have been checked.

## Classification Rules

| Classification | Meaning in this repository |
|---|---|
| `canonical` | Only permitted when an explicit Canon Register record supports it. |
| `reviewed_candidate` | Source-indexed material awaiting a review decision. |
| `legacy_source` | Preserved historical material, not current evidence by default. |
| `research/scenario` | Hypothesis, scenario, or research material requiring validation. |
| `quarantine/excluded` | Preserved but excluded from ordinary corpus projections under active policy. |
| `recovery_artifact` | Preserved reconstruction evidence requiring independent verification. |
| `unclassified` | Present in source inventory but not yet interpreted or promoted. |

## No Auto-Promotion

No PR, issue, ingestion process, or automation may convert this review index into a Canon Register entry without a separately recorded review decision and source evidence.
