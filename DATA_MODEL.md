# Source Index and Atomic Delta Model

The current release contains **671 source-index records**: 271 GitHub repositories and 400 accessible Notion records. These are individual, traceable source containers or records. They establish a review floor and preserve provenance, but they are not the final measure of atomic corpus deltas.

An **atomic delta** is a separately addressable contribution inside a source, such as an invariant, architecture change, interface contract, source module, data schema, test, policy, relationship, evidence receipt, recovery event, public route, or research proposition. Later releases will derive and deduplicate these atomic deltas from the source index, with every delta retaining its source container and locator.

This distinction prevents repository counts, document counts, and source inventory from being mistaken for the full intellectual or implementation delta count.
